# Profresource Go - демонстрационный проект

Profresource - пет-проект, в котором пользователи могут публиковать свои статьи и комментировать публикации других авторов. 
> Цель разработки - демонстрация практических навыков на языке Go.

## Требования к проекту
1. Регистрация и авторизация пользователя;
2. Просмотр статей;
3. Публикация, изменение и удаление своих статей;
4. Возможность оставлять и удалять собственные комментарии к статьям;

## Использованные технологии
1. MySQL
2. Go Fiber
3. Swagger - Описание доступных путей с возможностью их отработки

## Запуск проекта
1. Установить пакеты зависимостей. Для этого в вызвать следующую команду в корне проекта:
```
go mod download
```
2. Создать пустую MySQL базу данных.
3. Инициализировать .env файл (см. пример наименования переменных в .env.example файле в корне проекта).
4. Запустить проект:
```
go run main.go
```
5. После запуска проект будет доступен по адресу `http://localhost:4000`.

## Документация
Документация проекта описана с помощью `Swagger`. Доступна после запуска проекта по адресу:
```
http://localhost:4000/docs
```

## Сборка
Чтобы получить сборку проекта (исполняемый файл exe) выполнить команду:
```
go build main.go
```
После запуска исполняемого файла проект будет доступен по адресу http://localhost:4000.

## Дальнейшие доработки проекта
В будущем планируется следующий функционал:
1. Реализация системы ролей пользователей (администирование, модерация, пользователь).
2. Возможность редактирования комментариев.
3. Реализация многопоточности (goroutine) для запросов (Для распределения нагрузки на сервер).
