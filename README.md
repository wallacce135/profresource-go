# Profresource Go - демонстрационный проект

Profresource - небольшой проект, цель которого дать возможность пользователям писать свои статьи. Дргие пользователи могут просматривать эти статьи и комментировать их.
Данный проект создавался с целью демонстрации практических навыков на языке Go.

## Требования к проекту
1. Необходимо создать приложение в котором пользователь сможет зарегистрироваться и авторизоваться.
2. Необходимо было сделать возможность просматривать статьи.
3. Необходимо было сделать возможность оставлять, а также их удалять комментарии к статье.
4. Необходимо было сделать возможность добавлять/оставлять/редактировать статьи.
5. Необходимо было дать возможность регистрироваться и авторизовываться внутри системы.

## Последовательность разработки:
1. Разработать и спроектировать модель БД.
2. Настроить окружение и описать модели на языке Go.
3. Написать авторизацию с помощью Bearer JWT токена.
4. Написать контроллеры, которую будут принимать запросы.
5. Написать обработчики которые будут выполнять бизнес-логику
6. Сделать описание доступных методов с помощью swagger

## Использованные технологии
1. БД - MySQL
2. Go Fiber
3. Air - https://github.com/air-verse/air - данная утилита позволяет использовать функцию hot-reload, чтобы не было необходимости каждый раз перезапускать проект
4. Swagger - Описание доступных путей с возможностью их отработки

## Запуск проекта
После клонирования репозитория:
1. установить пакеты с зависимостями
```
go mod download
```
2. Создать пустую MySQL базу данных(например использую Open Server) или любой другой ресурс.
3. Инициализировать .env файл, пример наименования переменных доступен в .env.example файле в корне проекта.
4. Запустить проект
```
go run main.go
```
В случае, если необходимо получить исполняемый файл в формате .exe необходимо выполнить: go build main.go, после компиляции запустить исполняемый файл.
Проект будет доступен по адресу http://localhost:4000

Также в рамках проекта доступные пути описаны с помощью swagger, документацию можно найти по адресу - http://localhost:4000/docs
